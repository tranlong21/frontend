
1. NEON (PostgreSQL Serverless)
   - Connection String: Sử dụng chuỗi có `-pooler` để tối ưu hóa kết nối trong môi trường serverless.
   - SSL Mode: Bắt buộc `sslmode=require`.
   - Initialization: Chạy script khởi tạo Table `comments` (id, name, message, created_at).

2. RENDER (Backend - Java)
   - Build Command: `./mvnw clean install -DskipTests`
   - Start Command: `java -jar target/*.jar --spring.profiles.active=prod`
   - Environment Variables:
     * `SPRING_DATASOURCE_URL`: jdbc:postgresql://[host]/neondb?sslmode=require
     * `SPRING_DATASOURCE_USERNAME`: [user]
     * `SPRING_DATASOURCE_PASSWORD`: [password]
     * `CORS_ALLOWED_ORIGINS`: https://your-wedding-app.netlify.app
   - Health Check Path: `/actuator/health` (Cần add spring-boot-starter-actuator).

3. NETLIFY (Frontend - React)
   - Build Command: `npm run build`
   - Publish Directory: `dist`
   - Environment Variables:
     * `VITE_API_URL`: https://your-backend-service.onrender.com/api
   - SPA Routing: Tạo file `public/_redirects` với nội dung `/* /index.html 200` để tránh lỗi 404 khi refresh trang.
